# Славянский Сад

Сайт для души. Дом — `https://jektor27.github.io/slavsad/`.

Это не проект ради охватов и прибыли. Здесь собираются размышления о славянизме, ежедневные славянские статьи и сопоставление фрагментов разных Библий с авторским видением.

## Принцип

- Без гонки за лайками и раскруткой от имени автора.
- Там, где изложено личное видение, оно помечено как авторское.
- Там, где приведён источник, указано, откуда фрагмент.
- Слово «Славянская Библия» понимается как авторский свод заветов, а не как общепризнанный канон.

## Структура

- `index.html` — главная, три раздела.
- `osnova/index.html` — основа: что такое славянизм, боги, термины, заветы.
- `daily/index.html` — ежедневные статьи.
- `daily/article-template.html` — шаблон новой статьи.
- `sopostavlenie/index.html` — сопоставление фрагментов и авторское мнение.
- `sopostavlenie/comparison-template.html` — шаблон сопоставления.
- `css/style.css` — оформление, без внешних библиотек.

## Как вести

Скопируй нужный шаблон, переименуй файл, заполни текст. Новую статью добавь ссылкой в список своего раздела. Публикация на GitHub — только по прямому слову автора.
